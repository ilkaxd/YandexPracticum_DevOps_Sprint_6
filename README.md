## Задание

[к содержанию](#содержание)

Необходимо подготовить Ansible-роль для установки и настройки [Redis](https://redis.io/), которая:

- установит БД Redis;
- подготовит каталог для хранения данных;
- настроит конфигурационный файл;
- запустит сервис;

К роли предъявляются особые требования:

- установка должна выполняться только на системах семейства Debian;
- пароль Redis хранится в Ansible Vault;
- должны поддерживаться 2 окружения:
  - dev;
  - prod;

Отличия окружений:

| Параметр              | dev          | prod             |
| :-------------------- | :----------: | :--------------: |
| Порт                  | 6380         | 6379             |
| Количество баз данных | 4            | 16               |
| Каталог данных        | `/mnt/redis` | `/var/lib/redis` |
| Персистентность       | no           | yes              |

## Подготовка

[к содержанию](#содержание)

Для работы необходимо:

- установить Ansible на управляющей машине;
- настроить Ansible Vault для хранения секретов.

### Установка Ansible

[к содержанию](#содержание)

Установка Ansible осуществляется через pip.

- Создадим виртуальное окружение:

```bash
python -m venv venv
```

- Активируем виртуальное окружение:

```bash
. venv/bin/activate
```

- Установим Ansible:

```bash
pip install -r requirements.txt
```

### Настройка приватного ключа

Для работы необходим id_rsa в корне проекта

## Быстрый старт

[к содержанию](#содержание)

Ansible playbook можно запустить в двух вариантах:

- dev:

```bash
ansible-playbook playbook.yaml -i ./inventories/dev/inventory.yaml --ask-vault-pass
```

- prod:

```bash
ansible-playbook playbook.yaml -i ./inventories/prod/inventory.yaml --ask-vault-pass
```
